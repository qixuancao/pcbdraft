# 蓝桥杯 EDA 实战评测套件

本目录把蓝桥杯 EDA 设计与开发赛项真题改编为 PCBDraft 的实战评测任务，
用来回答“给定真实工程要求，PCBDraft 能否产出可审查的 KiCad 工程”，
而不是验证模型是否会做客观题。

## 为什么选蓝桥杯

- 题目是公开的工程任务：元件、封装、连接关系、DRC 规则、器件布局坐标、
  板层、铺铜和布线率都有明确要求。
- 题目有公开的参考设计（社区上传，非主办方标准答案），可用来建立
  人工复核基准，但**不得当作唯一正确布局**。
- 任务规模从小电路到完整小板，适合分阶段建立能力基线。
- 理论答案公开，因此客观题只能作为辅助诊断，不能当作实战成功证据。

## 与原赛题的差异（必须公开记录）

原赛题在嘉立创 EDA 专业版中完成，PCBDraft 产出 KiCad 工程。改编时：

1. **软件操作不计分**：元件库导入、导出 `.epro`/`.enet`、命名规则等
   软件流程要求改写为 KiCad 等价交付物（`.kicad_sch`/`.kicad_pcb`、
   工程内自定义符号与封装）。
2. **原理图/PCB 的工程内容按原题要求保留**：位号、网络名、器件参数、
   DRC 数值、布局坐标、板层与铺铜要求逐项保留，不做静默降级。
3. **元件/封装设计任务单独计分**：原题的“画 BCON 符号/SOP_BCON 封装”
   拆成独立里程碑；首跑允许把该符号与封装作为给定资源提供，并在报告中
   注明这一改编。
4. **参考答案不入运行工作区**：验收用网表、坐标和判定依据保存在仓库外的
   私有目录，运行时不向被测 Agent 暴露；报告只记录判定结果与证据。

## 判定原则

| 维度 | 判定内容 |
| --- | --- |
| 产物完整 | KiCad 工程可打开，原理图/PCB/工程文件齐全 |
| 电气正确 | 连接关系与参考网表一致；无缺失、错接、悬空 |
| 约束满足 | 板层、线宽、间距、过孔、布局坐标、铺铜、布线率 |
| 检查与复核 | ERC/DRC 按题目规则；人工复核极性、参数、封装、可制造性 |

**参考网表一致，不要求布局与参考答案逐像素相同。**

## 与 BoardBench 的关系

现有 [BoardBench v1](../../docs/BOARDBENCH.md) 负责活动组织、封存和证据链；
本套件提供**贴近真实工程的题目与参考契约**。正式活动应把本套件的任务
编译为 BoardBench corpus 案例（`component_slots`/`net_rules` 等字段），
并在有独立工程师复核前使用 `ai_reviewed_pilot` 队列标签。

候选规模、题干与验收契约均为整理结果，**尚未由人类工程师独立复核**，
不是封存基线，也不能当成生产能力证明。M1 的给定 BCON 资源是 AI
根据官方图 1/2 重建的输入材料；其 pin 电气类型统一声明为 passive，
因此 ERC 只覆盖连接/项目层面的有限检查，不能证明充电芯片的供电、驱动
或开漏语义。

`15th-province-p1-m1-v2` 仅是独立输入/评分契约修订：C13/C14 明确为非极性
`Device:C`，两端 pin 交换按对称两端规则处理；旧目录及旧单跑 fail 历史不变。
它是新的 input revision，不能与旧 M1 当作同题同输入直接比较；保留的是机器
可执行的器件/网络/几何/规则门槛，不是旧 prompt 的每一句文字。
题面没有可引用的 BCON 供电/电流限制、LED Vf 或 `current_limit` 参数，任务
不要求模型编造这些数值。ERC/DRC、完整 engineering candidate 和私有网表
topology 是相互独立的验收维度；任一 unknown 均不判为通过。
