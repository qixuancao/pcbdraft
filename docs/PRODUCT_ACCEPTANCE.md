# CopperWright v1 product acceptance

The historical R01–R44 traceability table establishes a bounded, deterministic
PCB engineering runtime. CopperWright is a complete end-user v1 only when one
authoritative application service supports both `copperwright chat` and
`copperwright app`, and the following paths are exercised with real evidence:

1. conversational create/open, focused clarification, assumptions, design brief,
   and explicit confirmation before side effects;
2. real KiCad generation, previews, L0–L7 validation, semantic modification,
   apply/undo, manufacturing-candidate release, and offline verification;
3. persistent projects, conversations, authoritative state, restart recovery,
   cancellation, concurrency protection, and safe provider handling;
4. browser and terminal end-to-end coverage over at least three materially
   different, fully verified low-voltage profiles, plus explicit unsupported
   states;
5. clean-install packaging, compatibility, security, browser, real-KiCad, and
   release gates, followed by new-user dogfooding and an exact final report.

Physical manufacture, live sourcing, qualified L6 review, and measured L7 results
remain external gates. No application state or model response can substitute for
them.
