Create a small passive RC interface PCB using only stock KiCad libraries. Provide an input connector, a 1 kohm 0805 series resistor, a node with a 100 nF 0805 capacitor to GND, and an output connector. Label the input, filtered output, and GND clearly, place and route the board, run native KiCad ERC and DRC, and render a real board.svg preview. This is a low-voltage, non-safety-critical tutorial, so preserve the editable native KiCad project and actual receipts without claiming fabrication or production readiness.
