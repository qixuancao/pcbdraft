# CopperWright example: ATtiny402 + TMP102 sensor controller

This is the runtime's accepted-scope end-to-end example: a two-layer, externally
regulated 3.3 V, non-safety-critical ATtiny402 controller with a TMP102 I2C sensor,
Qwiic connector, UPDI header, local decoupling, and current-limited status LED.
The generated board also carries a thermal-relief filled B.Cu GND reference plane,
two deterministic GND stitching vias, a 3.0-3.465 V (+5% maximum) supply envelope,
explicit 200 pF I2C and sense-only VTREF contracts, and native pad-edge decoupling
measurements in its managed manifest.

Generate it with:

```bash
copperwright generate examples/attiny_sensor_controller/requirements.json /tmp/controller
copperwright validate /tmp/controller --output /tmp/controller-validation --json
copperwright release /tmp/controller /tmp/controller-release --json
```

The checked-in `project/` directory is generated by the same command and is a real
KiCad project, not a hand-written mock. The checked-in acceptance evidence is under
`artifacts/acceptance/`. It is an **engineering candidate**, not a production sign-off:
live stock, qualified human review, fabrication, assembly, bring-up, EMC, and measured
physical results remain explicit external gates.
